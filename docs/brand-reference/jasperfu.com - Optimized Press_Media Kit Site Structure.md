## **Design system (carry over, unchanged from approved brand system)**

* **Palette:** Near-black \#0A0A0F (dark sections), off-white \#F4F6FA (light sections), brand blue \#0B72E7 (CTAs/links/accents only), white/near-black text per background, grey \#8A8F98 for captions  
* **Typography:** Bold heavy sans-serif headlines (Inter Bold or similar); all-caps letter-spaced section labels in brand blue; regular-weight body 16–18px; italic grey captions; bold italic pull-quotes with left blue rule  
* **Layout pattern:** Eyebrow label → headline → supporting copy, repeated per section. Two-column label/explanation layouts. Stat cards (solid blue block \+ off-white support cards). Blue-circle checkmarks for proof points, never plain bullets.  
* **Imagery:** Editorial/on-location over posed studio; NYSE still as reference point; logos always on clean background with clear space equal to logo height  
* **Tone:** Confident, understated, never crypto-hype. Dark sections \= identity/thesis moments only.
